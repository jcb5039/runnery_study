# 1~2주차 심화 확인 문제

목표는 이미 배운 변수·계산·조건문·반복문·리스트를 스스로 조합하는 것입니다. 새로운 함수를 만들거나 외부 파일을 읽는 문제는 없습니다.

## 푸는 순서

| 순서 | 파일 | 연습할 동작 |
| --- | --- | --- |
| 1 | [01_summary.dart](01_summary.dart) | 거리 합계와 조건에 맞는 횟수를 구분하기 |
| 2 | [02_valid_records.dart](02_valid_records.dart) | 세 가지 경우를 구분하고 필요한 값만 새 리스트에 모으기 |
| 3 | [03_reach_goal.dart](03_reach_goal.dart) | 목표 달성과 목록 끝을 고려해서 반복 종료하기 |

각 파일의 `main()` 안에 입력 변수 선언부터 직접 작성하세요. 처음 시작할 때는 TODO 아래에 작성하면 됩니다. 문제마다 사용할 변수 이름과 의미를 적어두었습니다. 풀이 예제와 정답 코드는 없습니다.

`var`와 `final`은 용도에 맞게 선택하세요. 합계·횟수처럼 다시 값을 넣는 변수는 `var` 또는 `int` 등 재대입 가능한 선언을 사용해야 합니다. 출력 문장 속 계산 결과를 숫자로 직접 써넣지 마세요.

문제의 지시를 다음처럼 구분해서 읽으세요.

- **꺼내세요:** 리스트의 항목을 반복문 안의 변수로 받아 사용하세요. 출력하라는 뜻이 아닙니다.
- **비교하세요:** 두 값의 관계를 조건식으로 검사하세요. 예: 하루 거리와 하루 목표를 비교합니다.
- **더해서 저장하세요 / 1 늘리세요:** 해당 변수의 값을 변경하세요.
- **리스트에 추가하세요:** `.add()`로 새 항목을 넣으세요.
- **출력하세요:** `print()`로 콘솔에 표시하세요.
- **실행 후 예상 출력과 비교하세요:** 완성한 파일을 실행하고 콘솔의 결과를 사람이 읽어 대조하세요.

각 문제는 **반복문 안에서 계산·비교·저장할 일**과 **반복이 끝난 뒤 출력할 일**을 나누어 적었습니다. 문제에서 요구하는 최종 출력은 각각 2줄, 4줄, 3줄입니다. 중간 값을 알아보려고 임시로 넣은 `print()`는 풀이를 마친 뒤 지워서 예상 출력과 맞추세요.

실행하려는 파일을 저장하고 아래 명령으로 실행합니다.

```bash
cd ~/src/runnery-study
dart run checkpoint02/01_summary.dart
```

2번을 실행할 때는 **명령어 끝의 파일명 부분**을 `02_valid_records.dart`로, 3번은 `03_reach_goal.dart`로 바꾸세요. 실제 파일의 이름을 변경하는 것이 아닙니다. 작성 전에는 `main()`이 비어 있어서 실행해도 아무것도 출력되지 않는 것이 정상입니다.

## 결과 확인 방법

1. 파일의 기본 입력값으로 실행한 뒤, 콘솔에 출력된 문장과 숫자를 문제의 예상 출력과 비교합니다.
2. 같은 파일에서 입력 변수에 저장할 값만 추가 실행 사례 A의 값으로 바꾸고 저장합니다.
3. 계산·조건·반복 코드는 그대로 두고 다시 실행한 뒤, 콘솔 출력을 사례 A의 예상 출력과 비교합니다.
4. 사례 B, C도 같은 방식으로 각각 실행합니다. 각 사례에 적힌 입력값을 모두 적용하세요.
5. 마지막에는 기본 입력값으로 되돌려 저장하고, 문제 아래 설명 질문에 주석으로 답합니다.

추가 사례를 위한 프로그램을 따로 만들거나 한 파일에서 모든 사례를 동시에 실행할 필요는 없습니다. 이 자료의 예상 출력은 직접 비교하기 위한 것으로, 자동 채점 코드는 없습니다.

문법 이름이 기억나지 않으면 찾아봐도 됩니다. 예를 들어 `.add()`의 사용법은 찾아보고 써도 됩니다. 반복문과 조건을 어떻게 조합할지는 먼저 직접 생각해 보세요.

## 다음 단계 판단

- 기본값과 다른 입력값에서 결과가 맞고, 변수의 역할과 반복 종료 이유를 설명할 수 있으면 3주차 함수로 넘어갑니다.
- 특정 문법만 찾아봤다면 그 사실을 적습니다. 그것만으로 미통과는 아닙니다.
- 풀이 구조를 설명받았다면 값을 바꾸어 혼자 다시 작성해 봅니다.
- 이 문제만으로 프로그래밍 실력 전체를 평가하지 않습니다. 다음 학습의 난이도를 정하는 확인 문제입니다.
