# 16주 최종 설명 기록

메모 변경 또는 기록 목록 새로고침 중 기능 하나를 선택하세요. 정답을 닫고 실습 파일과 Runnery 원본에서 각 단계를 직접 찾아요.

선택한 기능:

| 단계 | 실습 파일과 함수 | Runnery 파일과 함수 | 입력값과 결과 |
| --- | --- | --- | --- |
| 사용자 행동 | | | |
| 버튼 콜백 | | | |
| 데이터 처리 | | | |
| 기다림과 실패 처리 | | | |
| 상태 갱신 | | | |

직접 확인한 사례:

| 사례 | 실행 전 예상 | 실제 결과 | 다르면 수정할 위치 |
| --- | --- | --- | --- |

다음 단계로 가기 전 확인해요.

- 출력이나 화면을 입력값에서부터 예측할 수 있나요?
- `initState`, `build`, `dispose`와 앱 상태 변화가 각각 무엇인지 설명할 수 있나요?
- 메모리 값, 파일에 저장한 값, 서버에 전송한 값을 구분하나요?
- 예제 없이 비슷한 기능을 만들고 정상·빈 값·실패를 확인할 수 있나요?
- 모르는 코드 줄을 정확히 가리킬 수 있나요?

아직 어려운 개념과 다시 풀 날짜를 [학습 기록](../notes.md)에 적으세요. 16주는 학습 계획의 추정이며, 날짜보다 직접 예측하고 설명할 수 있는지가 기준이에요.
