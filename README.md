# Runnery를 읽기 위한 하루 90분 공부

지금 시작할 파일: [1주차 안내](week01/README.md) → [첫날 실습](week01/day01.dart)

## 지금 출발점과 예상 기간

2026-11-07 대화와 실습 화면 기준으로, 변수 선언과 출력을 직접 작성하는 단계입니다. 함수에 값을 전달하는 과정, 실행 순서, 오류와 경고를 구분하는 경험을 쌓고 있습니다. 아직 해보지 않은 영역의 실력을 단정하지는 않습니다.

매일 90분이면 일주일에 10.5시간입니다. 아래는 현재 출발점과 실제 Runnery 코드를 보고 잡은 학습 계획용 추정입니다. 공식 교육기관의 보장 기간이나 취업 준비 기간이 아닙니다.

| 목표 | 예상 누적 기간 | 매일 공부할 때 누적 시간 |
| --- | --- | --- |
| 짧은 Dart 코드의 실행 순서를 말하고 값을 바꿔 결과 예측하기 | 4~6주 | 42~63시간 |
| 작은 Flutter 화면을 읽고 버튼 동작을 설명하기 | 8~10주 | 84~105시간 |
| Runnery 주요 화면과 기록 저장 흐름을 문서의 도움을 받아 추적하기 | 12~16주, 약 3~4개월 | 126~168시간 |
| GPS·로그인·동기화까지 이해하고 작은 변경을 검증하며 수행하기 | 약 6개월 이상 | 개인차 큼 |

평일에만 90분씩 하면 주 7.5시간입니다. 같은 126~168시간은 약 17~23주가 걸립니다. 날짜보다 각 주의 통과 기준을 우선합니다.

Runnery의 `running_start_page.dart`는 확인 당시 약 2,320줄이고, GPS 처리·계산·화면 코드가 함께 들어 있습니다. 처음부터 파일 전체를 읽기보다 작은 함수와 한 가지 동작부터 따라갑니다.

## 매일 하는 순서

1. 10분: 어제 작성한 코드의 결과를 실행 전에 예측합니다.
2. 20분: 오늘 개념과 짧은 예제를 읽고 직접 실행합니다.
3. 45분: 오늘 실습을 작성합니다. 숫자를 바꾸어 한 번 더 실행합니다.
4. 15분: 작성한 코드를 말로 설명하고 [학습 기록](notes.md)에 적습니다.

주 6일은 새 내용과 실습, 7일째는 복습에 씁니다. 이해가 안 된 날은 같은 내용을 반복해도 됩니다. 문제 수를 채우려고 다음 개념으로 넘어가지 않습니다.

## 실행 방법

터미널에서 한 번 이동합니다.

```bash
cd ~/src/runnery-study
```

첫날 파일 실행:

```bash
dart run week01/day01.dart
```

파일을 수정하면 먼저 `⌘S`로 저장하고 다시 실행합니다. 각 파일에 독립된 `main()`이 있어서 그날 파일 하나만 실행하면 됩니다. 미완성 문제의 정답을 검사하는 코드는 없습니다. 예제의 출력 다음에 직접 작성한 코드의 출력이 이어집니다.

처음에는 이 폴더를 별도의 VS Code 창으로 열면 기존 학습 파일들의 경고와 섞이지 않습니다. 실습 중 변수 아래 노란 줄은 아직 사용하지 않았다는 경고일 수 있습니다. 빨간 오류는 실행 전에 고쳐야 합니다.

## 이해했다는 기준

정답을 복사해서 실행한 것만으로는 통과로 잡지 않습니다. 다음 세 가지가 되면 넘어갑니다.

- 코드 한 줄이 무엇을 하는지 내 말로 설명할 수 있습니다.
- 입력 숫자를 바꾸면 출력이 어떻게 달라질지 예측할 수 있습니다.
- 다음 날 비슷한 문제를 예제 없이 다시 풀 수 있습니다.
